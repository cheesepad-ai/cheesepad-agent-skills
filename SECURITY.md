# Security

## Report a vulnerability

Don't open a public issue. Report it privately from this repository's **Security** tab →
**Report a vulnerability**.

Say which skill and file are affected, what an attacker could do, and how to reproduce it.

## In scope

- Instructions that could make an agent send a transaction the user didn't approve, or send one
  to a contract other than CheesePad's.
- Instructions that could leak a key, seed phrase or wallet session.
- Wrong contract addresses or chain IDs.

Issues in the Binance Agentic Wallet, the `baw` CLI or an agent itself belong to their makers.
